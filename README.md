# Netflix Landing Page Clone 🎬

A Netflix-inspired landing page built using HTML and CSS.

## About the Project

This project is a frontend UI clone created to practice web development concepts and create a modern streaming platform interface.

## Technologies Used

- HTML
- CSS

## Concepts Practiced

- Flexbox layouts
- Positioning
- Layering and overlays
- Background images
- Responsive layout basics
- UI styling
